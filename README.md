# Ahmed Bedir | Data Analyst Portfolio

A single-page portfolio showing my data analytics work: Power BI dashboards, SQL case studies, and how I take a dataset from raw tables to a report people can act on.

I'm a data analyst based in Cairo, Egypt, working with Power BI, DAX, SQL and Excel on telecom, HR and retail data.

## What's inside

- **Selected work**: four Power BI dashboards with full-size screenshots
  - Sales Report Overview (8-page report: $1.72M sales, 12.36% profit margin, 2,010 orders)
  - Blinkit Sales Dashboard
  - Company Profit Analysis (2016 to 2019)
  - Regional Sales and Product Dashboard
- **Explore the numbers**: two interactive charts rebuilt from my dashboards (Blinkit by outlet type, profit by region)
- **Case studies**: four end-to-end projects from my Epsilon AI program
  - Mobily Telecom Performance
  - Etisalat Customer Behavior
  - HR Analytics Dashboard
  - Pizza Sales Analysis
- **How I work**: my workflow from source data to final report, plus skills and tools
- **Background**: education and training

## About the site

The portfolio is one self-contained `index.html` file: HTML, CSS and JavaScript with no build step and no dependencies. Dashboard screenshots are embedded as WebP images, so the file works on its own.

Features:

- Light and dark theme, saved in the browser
- Responsive layout for desktop and mobile
- Click-to-enlarge dashboard screenshots
- Keyboard-accessible navigation and focus styles

The only external resource is Google Fonts (DM Sans and Sora), with system font fallbacks.

## Run it locally

Download or clone the repository and open `index.html` in any browser.

```bash
git clone https://github.com/Ahmed-Badir/<repository-name>.git
cd <repository-name>
open index.html
```

## Deploy

It works on any static host, for example GitHub Pages: go to **Settings > Pages**, choose the `main` branch and the root folder, and save.
